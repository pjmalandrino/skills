# Design & UX

## Purpose

Visual design, interaction design, and UX research. Owned by designers and UX researchers, used when shaping how the product looks, feels, and what users actually need.

## When Claude should look here

- A user asks about UI patterns, visual hierarchy, accessibility, or the design system.
- A new screen or flow is being designed and needs wireframes, mocks, or a research plan.
- A user mentions: *wireframe*, *mockup*, *prototype*, *user research*, *interview*, *usability test*, *a11y*, *accessibility*, *design system*, *Figma*, *user flow*.

## Layout

- `rules/`      — design choices for this project (design system, accessibility level, brand guidelines)
- `specs/`      — current design system, component inventory, key user flows
- `references/` — generic theory (Nielsen heuristics, WCAG, common design-system patterns)
- `commands/`   — invocable skills (research-plan drafter, accessibility checker…)
- `templates/`  — research plan, usability-test script, design-review template
